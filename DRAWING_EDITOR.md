# Редактор чертежей в PSBees (векторный редактор: DXF, PDF, EPS, PLT, SVG)

Второй режим рабочего пространства PSBees — **«Чертежи»**: векторный редактор
для **чертежей, развёрток корпусов, коробок, панелей и деталей** с точным
выводом в **DXF**, **PDF**, **EPS**, **PLT** и **SVG** и импортом из тех же
форматов (обмен с CorelDRAW, AutoCAD, Illustrator и Inkscape).
Рядом с ним — **генератор коробок в отдельном окне** (кнопка «Коробки» в тулбаре
редактора чертежей или `Ctrl+B`). Переключатель режимов — в шапке:

| Режим | Что делает |
| --- | --- |
| **Платы** | редактор печатных плат (Sprint-Layout, Gerber, фрезеровка ЧПУ) |
| **Чертежи** | векторный редактор: узлы, кривые, булевы, DXF, PDF, EPS, PLT, SVG |
| **3D моделирование** | твердотельное 3D — **скоро в разработке** |

Выбранный режим запоминается в браузере. Плата при переключении не теряется:
состояние редактора плат остаётся в памяти, черновик — в хранилище браузера
(или в сеансе общего сервера), а проект — на сервере, если он сохранён в облаке.

> **Состав интерфейса.** Раздел работает как векторный редактор чертежей: вывод
> в DXF, PDF, EPS, PLT, SVG и свой формат проекта `.psdraw`, импорт из DXF, SVG,
> PDF, EPS/AI и PLT, генератор развёрток и окно коробок.
> Станочная часть — G-Code, симуляция обработки, задание на станок, режимы
> резки по слоям (мощность, скорость, проходы, обдув, керф), таблица материалов
> и PNG-чертёж — **скрыта из интерфейса, но сохранена в коде целиком**: её
> возвращает один флаг `MACHINE_UI` в `src/laser/features.ts`. Всё, что ниже
> описано как «станочное», работает именно под этим флагом.

> **Осторожно, если включите станочную часть: это программы для настоящего
> станка.** Мощность, скорость, число проходов и обдув зависят от вашей
> трубки/диода, оптики, материала и его партии. Значения из таблицы материалов —
> отправная точка. Сначала прогоните файл в симуляторе станка, затем сделайте
> пробный рез на обрезке того же листа. Не оставляйте станок без присмотра,
> используйте вытяжку и защитные очки.

## Как устроен интерфейс

```
┌──────────────────────────────────────────────────────────────────────────────┐
│ PSBees │ Платы · Чертежи · 3D │ файл │ отмена │ правка │ Коробки │ Развёртка │
├────────┬───────────────────────────────────────────────────────┬─────────────┤
│ вкладки│  лист (мм, Y вверх, 0;0 — левый нижний угол)           │ свойства    │
│ Объекты│                                                       │ сетка       │
│ /Слои  │        [док инструментов]                             │ лист и      │
│        │                                                       │ чертёж      │
├────────┴───────────────────────────────────────────────────────┴─────────────┤
│ X · Y · лист · объекты · слой · сетка · масштаб · длина контуров · черновик   │
└──────────────────────────────────────────────────────────────────────────────┘
```

Кнопки **«Коробки»** и **«Развёртка»** — подписанные, каждая в своей группе
тулбара редактора чертежей, и обе открывают самостоятельные окна (в шапке режима
«Платы» их нет). Левая колонка — две вкладки: **«Объекты»** (открыта по
умолчанию: дерево объектов листа и их свойства) и **«Слои»**. В строке
состояния — только чертёжные числа: координаты, формат листа, объекты, активный
слой, сетка, масштаб и длина контуров; станочных мощностей и скоростей там нет.

В станочном составе (`MACHINE_UI = true`) в шапке добавляется группа «станок»,
в правой колонке — панели «Материал и толщина» и «Задание на станок», а в строке
состояния — время обработки вместо длины контуров.

Всё в фирменном стиле PSBees: тёмная и светлая темы, золото на графите,
те же панели, виджеты и строка состояния, что в редакторе плат.

## Инструменты (док слева у холста)

| Клавиша | Инструмент | Как работать |
| --- | --- | --- |
| `V` | **Выбор** | клик — объект, Shift+клик — добавить, протяжка по пустому — рамка; маркеры вокруг выделения меняют размер |
| `F10` | **Форма (узлы)** | как Shape Tool в CorelDRAW: перетаскивание узлов и рычагов Безье, двойной клик по кривой — новый узел, по узлу — удалить, `S` — гладкий/угловой |
| `X` | **Усечь кривую** | как Trim/Extend в CAD: клик по кривой отрезает кусок до пересечения; `1` — усечь, `2` — продлить до границы, `3` — разрезать в точке; `Ctrl+Shift+X` — разбить всё по пересечениям |
| `H` | **Панорама** | двигает лист (то же — средняя кнопка мыши или удерживаемый пробел) |
| `P` | **Перо** | кривая Безье: клик — угловой узел, клик с протяжкой — гладкий с рычагами; Enter — закончить, клик по первому узлу — замкнуть контур |
| `L` | **Отрезок** | два клика; Shift — угол кратный 15° |
| `R` | **Прямоугольник** | протяжка; Shift — квадрат; скругление углов `rx` — в свойствах |
| `E` | **Эллипс / дуга** | протяжка; Shift — окружность; углы начала и конца дуги — в свойствах |
| `Y` | **Многоугольник / звезда** | протяжка задаёт габарит; число углов, звезда и внутренний радиус — в свойствах |
| `T` | **Текст** | клик ставит надпись штриховым шрифтом (как в шелкографии плат); кегль, толщину линии, поворот и зеркало меняйте в свойствах |
| `D` | **Размерная линия** | две точки + третий клик задаёт вынос; попадает на слой «Размеры», который станок не режет |

Колесо мыши — масштаб к курсору, `F` или `Ctrl+0` — весь лист, `Ctrl +`/`Ctrl −` — шаг масштаба.
Стрелки двигают выделенное на шаг сетки, с Shift — на 10 шагов.

## Слои чертежа

Слои **свои**: в новом чертеже один слой **«Слой 1»**, а дальше добавляйте
сколько нужно — «Слой 2», «Слой 3», … — и называйте как угодно. Имя слоя
редактируется прямо в строке списка, цвет берётся из палитры или из своего поля
цвета.

| Что сделать | Где |
| --- | --- |
| добавить слой | кнопка **«Слой»** под списком: новый получает имя по порядку |
| переименовать | поле имени в строке слоя — оно же имя слоя в DXF, PDF, EPS, PLT и SVG |
| удалить | крестик в строке слоя: объекты переходят на первый оставшийся; последний слой удалить нельзя |
| скрыть / показать | глаз в строке слоя: скрытый слой не попадает в экспорт; **«Показать все»** возвращает видимость |
| заблокировать | замок: объекты слоя не выделяются и не двигаются |
| цвет | образец цвета в строке слоя или палитра в свойствах активного слоя |
| тип линии | **«Тип линии»** в свойствах активного слоя |

**Тип линии** определяет, как слой попадёт в файл:

| Тип линии | Что это | В файле |
| --- | --- | --- |
| **Рез** | рабочие контуры деталей | сплошная линия |
| **Сгиб** | линии сгиба развёртки | пунктир: штрих и пропуск настраиваются (4 и 2 мм по умолчанию) |
| **Разметка** | лёгкий надрез, риски, маркировка | пунктир |
| **Заливка** | надписи и логотипы штриховкой | контуры штриховки |
| **Служебный** | размерные и осевые линии | остаётся на листе, в файл не попадает (кроме явного вывода служебного слоя) |

Имя слоя в файле — транслитерация его имени: «Слой 1» → `SLOY_1`, «Отверстия» →
`OTVERSTIYA` (AutoCAD не любит кириллицу и пробелы в именах слоёв). Порядок
слоёв в файле — порядок в списке. Новые объекты рисуются на **активном** слое:
он показан в строке состояния и в кнопке цвета слоя в тулбаре, им же управляет
панель «Слои».

> Станочные поля слоя — мощность, скорость, число проходов, керф и обдув —
> в интерфейсе рисовалки не показываются; они живут в модели документа и
> возвращаются флагом `MACHINE_UI`. Тогда же вместо своих слоёв работают
> фиксированные роли (`CUT`, `INNER`, `FOLD`, `SCORE`, `ENGRAVE`, `GUIDE`)
> с постоянным порядком обработки **гравировка → разметка → биговка →
> внутренние вырезы → внешний контур** и значениями по умолчанию: гравировка
> 30 % · 240 мм/с, разметка 22 % · 100 мм/с, сгиб 35 % · 45 мм/с, внутренний рез
> 85 % · 14 мм/с, резка 85 % · 15 мм/с, размеры — 0 проходов.

### Керф и перемычки (станочная часть, скрыта)

Компенсация толщины инструмента (**керф**) и удерживающие **перемычки**
(holding tabs) нужны станку, поэтому в интерфейсе рисовалки их нет: ни кнопок
«Керф наружу» / «Керф внутрь», ни поля «Перемычек, шт» в свойствах объекта, ни
флагов керфа и перемычек в параметрах DXF диалога экспорта.

Код сохранён и возвращается флагом `MACHINE_UI`: тогда керф смещает внешний
контур наружу на половину толщины инструмента, а отверстия — внутрь (деталь
после реза получается точно по чертежу), перемычки разрывают контур короткими
«мостиками» и видны на холсте квадратиками, а их число и ширина задаются в
свойствах объекта.

## Материал и толщина

В рисовалке от материала нужна только **толщина**: её использует генератор
развёрток и генератор коробок (глубина пазов, высота шипов, клапаны, зазоры
посадки). Поле **«Толщина, мм»** стоит в панели «Лист и чертёж» справа.

Панель **«Материал и толщина»** с готовыми режимами резки — фанера 3/4/6 мм,
акрил 3 мм, картон 1,5 мм, МДФ 3 мм, ПЭТ 0,8 мм — относится к станочной части:
выбор пресета прописывает мощность, скорость, проходы и керф во все слои, а
кнопка **«Таблица режимов резки»** показывает все пресеты сразу. Панель
возвращается флагом `MACHINE_UI`.

## Генератор развёрток — отдельное окно

Открывается кнопкой **«Развёртка»** в тулбаре редактора чертежей: вкладки
«Развёртка» в левой колонке больше нет. Окно устроено как остальные окна
программы — слева параметры, справа **предпросмотр** раскладки в масштабе со
сводкой (объекты, габарит, длина контуров, влезает ли в лист).

Семь параметрических шаблонов — все строятся сразу по нескольким слоям
(контур, окна, линии сгиба, маркировка, размеры) и объединяются в группу:

1. **Складная развёртка коробки** — единый контур из одного листа с клапанами
   склейки, пунктирными линиями сгиба, откидной крышкой с замковым язычком
   и отверстиями под стойки печатной платы в дне.
2. **Корпус на шипах (Фанера / Акрил)** — шесть стенок с настоящим расчётом
   шип-паз под толщину листа: дно и крышка с пазами, стенки с шипами, подрезка
   углов, крышку можно отключить («Открытый верх»). Зазор посадки (`clearance`)
   расширяет пазы, чтобы корпус собирался без шлифовки, а габариты деталей
   остаются точными. В дне — отверстия под плату по базе `X × Y` и диаметру
   винта. Геометрию считает общий движок коробок (`src/laser/boxes.ts`), тот же,
   что и в **«Генераторе коробок»** — см. ниже.
3. **П-образное шасси прибора** — листовая развёртка корпуса под печатную плату:
   база с отверстиями под стойки, два борта с линиями гиба и вентиляционными
   пазами.
4. **Развёртка цилиндра / конуса** — если верхний и нижний диаметры равны,
   строится прямоугольная боковая развёртка `πD × H` с клапаном шва, линией
   сгиба и донышками; если разные — точный круговой сектор усечённого конуса.
5. **Лицевая панель прибора** — контур со скруглением, четыре крепёжных
   отверстия, окно дисплея с декоративной рамкой, отверстия регуляторов с
   дуговыми шкалами и надпись на слое гравировки.
6. **Гибкий рез (Живой шарнир)** — шахматный паттерн прорезей, который
   позволяет согнуть фанеру или акрил на 90…180° без петли.
7. **Зубчатое колесо (Шестерня)** — профиль зуба по модулю `m` и числу зубьев
   `Z`, делительная окружность на слое разметки и отверстие под вал.

Кнопка **«Построить развёртку на листе»** считает развёртку и показывает её в
предпросмотре, а **«Перенести на лист»** добавляет детали на текущий лист и
сразу их выделяет. Детали ложатся на свои слои чертежа: контуры — на рабочий
слой, линии сгиба и маркировка получают собственные слои, размерные линии —
служебный слой «Размеры». Если развёртка не влезает в лист — окно предупредит
(увеличьте лист в «Размер листа и название…» или уменьшите деталь).

## Генератор коробок — отдельное окно (`Ctrl+B`)

Самостоятельное окно программы — каталог из **28 параметрических генераторов**
(450 настроек) в духе box.laserbiz.ru / boxes.py, но с предпросмотром сборки и
точным DXF на выходе.

Открывается подписанной кнопкой **«Коробки»** в собственной группе тулбара
редактора чертежей или `Ctrl+B`. В шапке редактора плат этой кнопки нет: коробки — инструмент чертежа,
а не платы. Окно работает **со своим листом** (600×400 мм по умолчанию, лист
подбирается кнопкой «Подобрать лист»), поэтому коробку можно собрать и забрать
в DXF или SVG, вообще не заходя в рисовалку. Кнопка **«Перенести в рисовалку»**
отдаёт раскладку редактору чертежей: если режим не активен, программа переключит
его сама и поместит детали на лист.

Окно разделено на три колонки:

**1. Каталог** — поиск по названию и описанию, фильтр по семействам и карточки
с миниатюрой раскроя:

| Семейство | Генераторы |
| --- | --- |
| Коробки | универсальная, с основанием, закрытая, закруглённая по секциям, U-образная (гнутое дно), со скосом |
| Крышки и петли | крышка и низ, коробка с бортиком, коробка с петлями-гребёнками, встроенные петли (живой шарнир) |
| Лотки и ящики | выдвижной ящик, лоток с захватами и штабелируемыми ножками, лоток для бумаг, лоток с разделителями |
| Приборные | монтажный короб, рэковый корпус 19″ с ушками, лицевая панель, перфорация (решётка отверстий), стойка для плат |
| Механика | крепление NEMA, панель соединения на ласточкином хвосте, зубчатая пара |
| Бытовое | скворечник, корзинка для приборов с ручкой, салфетница, катушка |
| Мастерская | вогнутая ручка, настенный держатель инструмента |

**2. Предпросмотр** — два режима: **«Сборка»** (аксонометрия, крутится мышью,
грани подсвечены по освещённости, в подсказке — имя детали) и **«Раскладка»**
(детали на листе в масштабе, цветами слоёв). Под превью — статистика: число
деталей, длина контуров и линий сгиба в метрах, габарит сборки и влезает ли раскладка
в лист. Кнопка **«Подобрать лист»** находит наименьший стандартный формат листа,
на котором помещается всё. Здесь же зазор раскладки, отступ от края и размер листа.

**3. Параметры** — форма строится из схемы генератора и разбита на разделы
(«Размеры», «Материал», «Соединение», «Кромки», «Леток»…). Кнопка
**«Тонкие настройки»** раскрывает угол хвоста, отступ от края, начало кромки,
удлинение шипа и коррекцию реза. **«Сброс»** возвращает значения по умолчанию.
Параметры каждого типа запоминаются отдельно — можно сравнивать генераторы.

Общие настройки соединения (как в boxes.py):

| Параметр | Что делает |
| --- | --- |
| Толщина материала | толщина листа; от неё зависят все замки и подрезка углов |
| Вид шипа | шип-паз (`finger`) или ласточкин хвост (`dovetail`) |
| Ширина шипа | целевая ширина пальца; пальцев всегда нечётное число, кромка симметрична |
| Люфт (`play`) | расширяет паз на `2·play` с каждой стороны — сборка без шлифовки |
| Коррекция реза (`burn`) | дополнительная компенсация обгара: паз становится шире |
| Отступ от края (`edgeWidth`) | сплошная полоса в начале и конце кромки |
| Начало кромки (`surroundings`) | кромка начинается с шипа или с пробела |
| Удлинение шипа (`extra`) | выпуск под шлифовку обгорелых торцов |
| Подписать детали | маркировка каждой детали на слое гравировки |
| Эталон | прямоугольник заданной длины для проверки масштаба после резки |

Правила геометрии (их автоматически проверяет `npm run test:boxes`):

- угловой квадрат `t×t` не режется — у кромок есть подрезка, поэтому шипы
  соседних деталей не спорят в углу;
- подрезка считается по фактическому углу детали и по направлению обхода
  кромки: передняя и боковая стенка всегда попадают в одни и те же пазы дна,
  иначе замок разъезжается на толщину листа;
- боковые стенки короче дна на две толщины, поэтому их низ и верх не подрезаются;
- раструб «ласточкина хвоста» обрезается по границе замка, а паз строится по
  внешнему контуру хвоста: перпендикулярные детали собираются без подпиливания
  (настоящая фиксация на отрыв — там, где соединение собирается сдвигом:
  U-образная коробка, выдвижной ящик, панель соединения);
- **детали в сборке не пересекаются**: тест проходит сеткой по всему объёму
  сборки для всех 28 генераторов, всех сочетаний кромок и обоих видов шипа;
- размеры выдерживаются точно: `outside` переключает внутренние габариты
  и наружные, а секции закруглённой коробки задаются строкой `30:25:70`,
  `50*4` или `250/3`.

Кнопки внизу: **«Поместить на лист»** (раскладка добавляется в документ,
выделяется и попадает в историю — `Ctrl+Z` отменяет), **«DXF»** и **«SVG»**
(скачиваются сразу, лист не меняют). При раскладке детали ложатся на свои слои
чертежа: контур и отверстия (круги остаются точными окружностями и в DXF) — на
рабочий слой, линии сгиба — на слой с типом линии «Сгиб», подписи — на слой
заливки. В станочном составе (`MACHINE_UI`) те же детали распределяются по ролям
`CUT`/`INNER`/`FOLD`/`ENGRAVE`, а перемычки настраиваются в диалоге экспорта.

Шаблон развёртки **«Корпус на шипах»** считает геометрию тем же движком,
поэтому замки у обоих инструментов одинаковые.

## Усечь кривую (`X`)

Инструмент работает как `TRIM`/`EXTEND` в САПР и «Обрезать» в CorelDRAW:
кривая режется **по настоящим пересечениям** с другими объектами, а не по
их габаритам. Всё считается по кривой Безье (сегменты делятся точно,
де Кастельжо), поэтому дуга после усечения остаётся дугой, а не ломаной.

Под курсором подсвечивается кусок, который будет удалён, и точки реза —
клик применяется сразу, без диалогов.

| Режим | Клавиша | Что делает |
| --- | --- | --- |
| **Усечь** | `1` | кривая делится во всех пересечениях, кусок под курсором удаляется. Замкнутому контуру нужно минимум два пересечения, открытой кривой — одно |
| **Продлить** | `2` | ближайший к клику конец кривой дотягивается по касательной до первой границы на пути (в сообщении — на сколько миллиметров) |
| **Разрезать** | `3` | кривая делится ровно в точке клика: замкнутый контур становится открытым, открытый отрезок — двумя кривыми |

- **Границы** — любые видимые объекты листа: кривые, прямоугольники,
  окружности, текст-кривые, а также **край листа**. Скрытые и заблокированные
  объекты, размерные линии и слой «Размеры» (направляющие) границами не
  считаются и сами не усекаются — служебная графика в файлы не выводится.
- **Самопересечения** тоже режут: «восьмёрка» усечётся в собственной петле.
- **Контур с отверстиями**: режется тот контур, по которому кликнули,
  отверстия сохраняются отдельными замкнутыми кривыми.
- Флажок **«границы — выделенные»** сужает набор границ до выделенных
  объектов: удобно резать одну деталь, не задевая соседние. Выделение при
  этом не сбрасывается, так что серию резов можно делать подряд.
- **`Ctrl+Shift+X` — «Разбить по пересечениям»**: все выделенные кривые
  (без выделения — весь лист) делятся во всех точках пересечений, как
  `Split at intersections` в CAD.
- Куски наследуют слой, группу и имя (`… · часть 1`), встают в списке
  объектов на место удалённой кривой, перемычки и заливка открытых кусков
  не наследуются. Действие отменяется `Ctrl+Z` как одно целое.
- Касание в одной точке (конец кривой лежит ровно на границе) пересечением
  не считается — нулевые куски не появляются.

Кнопки тех же режимов есть в панели свойств справа (блок «Усечь кривую»).

## Операции CorelDRAW

В шапке и в панели свойств справа:

- **Булевы**: объединение (Weld, `Alt+W`), вычитание (Trim, `Alt+T`),
  пересечение (Intersect, `Alt+I`), исключение (XOR, `Alt+X`). Первый
  (нижний по порядку) объект — целевой, как в CorelDRAW. Вложенные объекты
  становятся отверстиями.
- **Контур / отступ** — эквидистанта на заданное расстояние наружу или внутрь
  с переносом на любой слой (например, сделать паз на 0,3 мм свободнее).
- **Скругление углов (Fillet)** — кнопки `R1 R2 R3 R5` или свой радиус.
- **Усечь / продлить / разбить** — см. раздел «Усечь кривую (`X`)».
- **В кривые (`Ctrl+Q`)** — прямоугольник, эллипс, многоугольник и текст
  превращаются в редактируемые кривые Безье (окружность — ровно 4 узла с
  правильными рычагами).
- **Выравнивание и распределение** — по левому/правому краю, по верху/низу,
  по центрам, по центру листа, равномерное распределение по X и Y (от 3 объектов).
- **Порядок** — на передний/задний план и на один уровень вверх/вниз.
- **Группы** — `Ctrl+G` / `Ctrl+Shift+G`; группа двигается и выделяется целиком
  (двойной клик по объекту выделяет его группу).
- **Размножение массивом (Step & Repeat)** — строки × столбцы с зазорами.
- **Автораскладка** — детали автоматически раскладываются на листе полками
  (bin packing) с полями 5 мм и зазором 3 мм; вложенные отверстия и
  сгруппированные объекты едут вместе со своей панелью.
- **Блокировка и скрытие** отдельных объектов и целых слоёв.
- **Векторизация изображения** — как PowerTRACE: растровый логотип
  превращается в замкнутые контуры с отверстиями (порог яркости, инверсия,
  ширина в мм, отбрасывание мелких пятен, упрощение Дугласа-Пекера).

Объекты можно править и числами в свойствах: позиция, габарит, поворот,
радиусы, число углов, кегль текста и т.д.

## Экспорт чертежа

Кнопка **«Экспорт чертежа…»** (`Ctrl+E`) в шапке редактора или в панели «Лист и
чертёж». В диалоге шесть форматов — DXF открыт сразу:

| Формат | Для чего |
| --- | --- |
| **AutoCAD DXF** (`.dxf`) | основной формат вывода: точный чертёж 1:1 в миллиметрах по своим слоям чертежа — для CorelDRAW, AutoCAD, Adobe Illustrator, Inkscape и Компас-3D. Подробности ниже |
| **PDF 1:1 мм** (`.pdf`) | векторный PDF: кривые Безье без аппроксимации, 1 мм = 2.8346 пт, слои чертежа становятся слоями PDF (OCG) — CorelDRAW, Illustrator, Inkscape и Acrobat разбирают файл по слоям |
| **EPS / PostScript** (`.eps`) | EPS 3.0 с `%%BoundingBox` по размеру листа, цветами, пунктиром и метками `%PSBeesLayer` — для CorelDRAW и Illustrator |
| **PLT (HPGL/2)** (`.plt`) | формат плоттеров: 40 юнитов на мм (1 юнит = 0.025 мм), своё перо на каждый слой, пунктир линий сгиба — настоящими пропусками пера |
| **SVG 1:1 мм** (`.svg`) | группы по слоям, пунктир линий сгиба, имена объектов в `data-name` — для Inkscape, Illustrator, CorelDRAW и просмотра в браузере |
| **Проект PSBees** (`.psdraw`) | весь проект: лист, слои, толщина, объекты и группы — открывается обратно в редакторе (`Ctrl+S` сохраняет его сразу; прежние `.pslaser` читаются) |

Для PDF, EPS, PLT и SVG в диалоге есть **параметры векторного файла**: толщина
линии в миллиметрах, слои чертежа как слои PDF (OCG), отдельное перо на каждый
слой для PLT, допуск аппроксимации кривых для PLT, а также вывод служебного
слоя и скрытых объектов. Там же — подсказка про обмен с CorelDRAW и про то,
почему `.cdr` нужно пересохранять.

В станочном составе (`MACHINE_UI = true`) к ним добавляются **PNG-чертёж**
(растр в масштабе для документации и печати 1:1) и **G-Code** (`.gcode` / `.nc`)
— управляющая программа для GRBL / LightBurn / LaserGRBL: `G21 G90`, `M3`/`M4`,
мощность в `S`, подача `F` в мм/мин, проходы, `M8`/`M9` обдув, оптимизированные
холостые `G0`, возврат в ноль и `M2`; вместе с ней появляется и панель
«Параметры G-Code».

Все настройки DXF из таблицы ниже доступны прямо в диалоге экспорта на вкладке
**«AutoCAD DXF»** — ничего не нужно править в коде или запоминать: версия,
сущности, единицы, ноль координат, состав слоёв, цвета, пунктир сгиба, допуск,
масштаб, сварка точек, инверсия Y, текст, блоки, скрытые объекты и вывод
служебного слоя, комментарий в шапке (в станочном составе — ещё керф и
перемычки). Там же видно **план файла**
(какие слои попадут в DXF, их цвета ACI, типы линий и число объектов) и
**живой контроль точности**: максимальное отклонение геометрии файла от
исходной, отклонение габарита и длины контуров — пересчитывается после каждой
правки настроек (на очень больших листах проверка пропускается, чтобы не
тормозить диалог).

### Точный DXF

Модуль `src/laser/dxf.ts` пишет полноценный файл AutoCAD, а не «ломаную из
отрезков»: геометрия остаётся геометрией, миллиметры — миллиметрами.

| Параметр | Значения | Что даёт |
| --- | --- | --- |
| Версия | **R2000** (`AC1015`, по умолчанию) / R12 (`AC1009`) | R2000 — полный DXF с дескрипторами, подклассами, `BLOCK_RECORD`, секциями `CLASSES`/`OBJECTS`; R12 — для старых CAM |
| Сущности | **авто** / точно / полилинии / отрезки | «точно» — `CIRCLE`, `ARC`, `ELLIPSE`, `SPLINE` и скругления бульджами; «авто» — то же, но сплайны/эллипсы только в R2000; «полилинии» — списки точек; «отрезки» — только `LINE` |
| Единицы | **мм** / дюймы | `$INSUNITS` = 4 или 1, `$MEASUREMENT`, `$LUNITS`, `$LUPREC` |
| Точность | 1…9 знаков (по умолчанию 6) | округление координат; безразмерные параметры (отношение осей, углы, бульджи, узлы сплайна) пишутся точнее, чтобы округление не усиливалось радиусом |
| Ноль координат | **угол листа** / габарит деталей / центр / без сдвига | сдвиг всей геометрии |
| Инверсия Y | выкл / вкл | зеркало относительно верха кадра — для программ с отсчётом сверху |
| Допуск | 0.0005…5 мм (по умолчанию 0.01) | точность аппроксимации кривых, если они раскрываются в точки |
| Слои | **слои чертежа** / один слой / по объектам | свои имена слоёв транслитерируются и приводятся к допустимым для AutoCAD |
| Цвета | **ACI** / точный RGB (код 420) / ByLayer | красный — внешний контур, как принято в CAM-программах |
| Пунктир сгиба | **штрихами** / тип линии `DASHED` / сплошной | штрихи — физическими отрезками, `DASHED` — таблицей `LTYPE` |
| Керф *(станочная часть)* | выкл / вкл | внешний контур уходит наружу на `kerf/2`, отверстия — внутрь: деталь после реза получается точно по чертежу |
| Перемычки *(станочная часть)* | вкл / выкл | удерживающие перемычки разрывают контур |
| Блоки | выкл / вкл | одинаковые детали становятся `BLOCK` + `INSERT` (файл заметно короче) |
| Текст | штриховые контуры / сущность `TEXT` | контуры открываются в любой программе, `TEXT` остаётся редактируемым текстом в CAD |

Дополнительно: скрытые объекты и служебный слой «Размеры» по умолчанию не
экспортируются; кириллица в именах слоёв и тексте — через `$DWGCODEPAGE
ANSI_1251`; координаты пишутся без экспоненциальной записи и «минус нуля»;
`$EXTMIN`/`$EXTMAX` считаются по реальной геометрии; `$HANDSEED` больше всех
выданных дескрипторов.

**Контроль точности.** Функции `analyzeDxf()` и `measureDxfAccuracy()`
возвращают отчёт по готовому файлу: версия, единицы, состав сущностей, слои,
габарит, число замкнутых и открытых контуров, длина реза, замечания и
справочные сообщения, а также максимальное и среднее отклонение геометрии
файла от исходной (в мм), отклонение габарита и длины в процентах. Эталоном
служит идеальная геометрия с мелким допуском, поэтому отчёт честно показывает
и огрубление аппроксимации. По умолчанию отклонение не превышает **0.00001 мм**.

**Отдельные файлы по слоям** (`exportDxfPerLayer`) — `CUT.dxf`, `INNER.dxf`,
`FOLD.dxf`, `SCORE.dxf`, `ENGRAVE.dxf`: удобно, когда CAM-программа настраивает
режимы по файлу, а не по слою. В диалоге экспорта режим переключается парой
кнопок **«Один файл» / «Файлы по слоям»**; во втором случае файлы складываются
в архив `<имя проекта>.zip` (пустые слои и слой «Размеры» без явного запроса не
создаются), а список будущих файлов с числом объектов показан заранее. Каждый
файл разбивки — полноценный DXF со своими настройками и тем же контролем
точности, что и единый файл.

**Импорт DXF** читает `LINE`, `CIRCLE`, `ARC`, `ELLIPSE`, `LWPOLYLINE`,
`POLYLINE`+`VERTEX`, `SPLINE`, `TEXT`/`MTEXT` и раскрывает `INSERT` (в том
числе с масштабом и поворотом). Бульджи превращаются в настоящие дуги,
окружности остаются окружностями, слой определяется по имени (`CUT`, `FOLD`, …)
или по цвету ACI, а координаты переводятся в миллиметры по `$INSUNITS`.

**Импорт**: `Ctrl+O` читает `.psdraw`/`.pslaser`/`.json` (свой проект), а также
**SVG, DXF, PDF, EPS/AI и PLT** из внешних редакторов — контуры, кривые Безье,
прямоугольники, окружности, ломаные и полигоны; слой определяется по имени
группы/слоя, по имени слоя PDF (OCG) или по пунктиру (линии сгиба). Импорт
автоматически переносится в пределы листа. Подробный разбор форматов — в
разделе «Импорт чертежей: CorelDRAW, AutoCAD, Illustrator».

Слой «Размеры» в экспорт не попадает — это служебная графика.

## Импорт чертежей: CorelDRAW, AutoCAD, Illustrator

Кнопка **«Открыть проект или импорт»** (`Ctrl+O`) принимает:

| Формат | Что читаем |
| --- | --- |
| **Проект** `.psdraw` / `.pslaser` / `.json` | проект целиком: лист, слои, объекты, группы |
| **DXF** | `LINE`, `LWPOLYLINE`, `POLYLINE`, `CIRCLE`, `ARC`, `ELLIPSE`, `SPLINE`, `INSERT` (блоки), слои и их цвета, единицы файла |
| **SVG** | пути и примитивы, группы с `transform`, `viewBox` и размеры в мм/см/дюймах/пунктах, слой по `id`/`data-layer` |
| **PDF** (и свежий **AI**) | векторные потоки страниц: `m l c v y h re`, `S f B`, матрицы `q Q cm`, формы XObject (`Do`), слои OCG, сжатые потоки `FlateDecode`, `ASCII85Decode`, `ASCIIHexDecode` и object-потоки PDF 1.5 |
| **EPS / PS / старый AI** | мини-интерпретатор PostScript: `moveto`, `lineto`, `curveto`, `rcurveto`, `closepath`, `arc`, `arcn`, `arct`, матрицы `translate/scale/rotate/concat`, `gsave/grestore`, цвета `setrgbcolor/setcmykcolor`, пунктир `setdash`, процедуры из пролога (`/L { lineto } def`) и операторы Illustrator (`u/U/*u/*U/n/N/F/f/S/s/B/b`) наряду с PDF-диалектом (`q/Q/cm/re/m/l/c/h`) |
| **PLT / HPGL** | `PU/PD/PA/PR`, дуги `AA/AR`, окружности `CI`, прямоугольники `RA/RR/EA`, перо `SP` → слой, масштаб `SC` с окном `IP`, единицы `IU`, поворот `RO` |

Слои при импорте определяются так: имена слоёв PDF (OCG) и метки `%PSBeesLayer`
в EPS дают точное соответствие; иначе пунктир линии отправляет объект на слой
сгиба, а цвет линии сравнивается с цветами слоёв чертежа; в крайнем случае
объект попадает на основной контур. Координаты всегда в миллиметрах, ось `Y`
вверх, масштаб 1:1 — ни PDF, ни EPS, ни PLT чертёж не переворачивают и не
масштабируют.

**Родной формат CorelDRAW `.cdr` не читается**: он закрытый и двоичный,
публичной спецификации нет, браузерных парсеров не существует (libcdr — это
C++-библиотека). При попытке открыть `.cdr` редактор показывает подсказку:
сохраните чертёж из CorelDRAW через «Файл → Опубликовать в PDF» или «Файл →
Экспорт» в EPS, SVG, DXF или PLT — все эти форматы читаются.

Что импорт **не** берёт: текст, не переведённый в кривые (в CorelDRAW —
«Преобразовать в кривые», в Illustrator — Type → Create Outlines), растровые
вставки, маски и области обрезки (clip). Обо всём этом сообщается в строке
состояния после импорта.

## Симуляция обработки (станочная часть, скрыта)

Симуляция относится к станочной части и в интерфейсе рисовалки не показывается;
код сохранён и возвращается флагом `MACHINE_UI`. Кнопка **«Рассчитать и
симуляция»** строит реальную траекторию головки:

- учитывает мощность, скорость и число проходов каждого слоя;
- применяет керф, перфорацию биговки и перемычки;
- оптимизирует холостые переезды методом ближайшего соседа (меньше пути `G0`
  и меньше следов на материале);
- показывает длину реза, длину холостого хода, общее время и разбивку по слоям.

В окне симуляции траектория проигрывается с ускорением ×1…×256: пройденный
путь подсвечен цветом слоя, будущий — серый, головка видна перекрестием,
есть пуск/пауза, возврат в начало и полоса прогресса.

## Горячие клавиши режима «Чертежи»

| Сочетание | Действие |
| --- | --- |
| `V` `F10` `X` `H` `P` `L` `R` `E` `Y` `T` `D` | выбор инструмента |
| `1` `2` `3` | режим инструмента «Усечь кривую»: усечь / продлить / разрезать |
| `Ctrl+Shift+X` | разбить кривые по всем точкам пересечений |
| `Ctrl+Z` / `Ctrl+Y` | отменить / повторить |
| `Ctrl+A` | выделить всё |
| `Ctrl+D` | дублировать |
| `Del` | удалить объект (в режиме «Форма» — удалить узел) |
| `Ctrl+G` / `Ctrl+Shift+G` | сгруппировать / разгруппировать |
| `Ctrl+Q` | в кривые |
| `Alt+W` `Alt+T` `Alt+I` `Alt+X` | объединить, вычесть, пересечь, исключить |
| `Ctrl+S` | сохранить проект `.psdraw` |
| `Ctrl+O` | открыть проект / импорт SVG, DXF, PDF, EPS/AI, PLT |
| `Ctrl+E` | экспорт чертежа (DXF, PDF, EPS, PLT, SVG, проект) |
| `Ctrl+B` | генератор коробок — отдельное окно (каталог из 28 типов) |
| `Ctrl+N` | новый лист |
| `F2` | размер листа и название |
| `F` / `Ctrl+0` | показать весь лист |
| `Ctrl +` / `Ctrl −` | масштаб |
| `Enter` | закончить кривую / отрезок / размер |
| `Esc` | отменить рисование, снять выделение, закрыть окно |
| `Alt` (удерживать) | временно отключить привязку |
| пробел (удерживать) | панорама листа |

Горячие клавиши редактора плат в этом режиме не действуют — и наоборот:
правка невидимой платы из режима чертежей невозможна.

## Единицы и система координат

Всё в **миллиметрах**, `Y` направлен **вверх**, начало координат `(0;0)` —
**левый нижний угол листа** (так же устроены DXF, PDF, PostScript и HPGL,
поэтому ни один из форматов обмена не зеркалит чертёж). Размер листа задаётся в
«Размер листа и название…» (`F2`): пресеты A4 (297×210), A3 (420×297),
A2 (594×420), A1 (841×594), 300×200, 600×400, 1000×700 мм или свой размер.
В станочном составе (`MACHINE_UI`) тот же диалог называется «Размер стола и
материал…», а пресеты — это столы станков: K40 320×220, 6040 600×400,
9060 900×600, 1390 1300×900, диодные A4/A3.
