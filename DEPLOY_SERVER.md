# Запуск общего сервера PSBees — подробный гайд для новичков

Этот гайд написан максимально просто: **вам не нужно разбираться в серверах, базах данных, почте или настройках Linux**. Просто копируйте команды по порядку.

### Что даёт общий сервер?
- Вы запускаете сервер на **одном компьютере** (или сервере).
- **Другие люди** (в вашей локальной сети Wi-Fi / проводной сети или через VPN вроде Radmin VPN / Tailscale / ZeroTier) просто открывают адрес вашего сервера в обычном браузере — им **не нужно ничего устанавливать**.
- **Никакой почты и паролей:** при входе человек просто пишет своё **имя или ник** (например, `Данил`, `Алексей`, `Инженер1`) и сразу попадает в редактор.
- **Первый вошедший человек** автоматически становится **администратором сервера** и получает доступ к админ-панели (`/admin`).
- Все платы, версии проектов и общая библиотека деталей сохраняются на сервере и не пропадают после перезагрузки.
- Двое людей могут **одновременно редактировать одну плату** в реальном времени.

cd ~/linux_pcb_app

## Шаг 1. Как открыть терминал и вводить команды

1. Нажмите на клавиатуре сочетание клавиш **`Ctrl + Alt + T`** (или нажмите клавишу **Win / Super**, напишите `терминал` и нажмите **Enter**).
2. Откроется тёмное окно — это терминал.
3. **Как вставлять команды:** скопируйте команду из этой инструкции, кликните в окно терминала **правой кнопкой мыши → «Вставить»** (или нажмите **`Ctrl + Shift + V`** — обычное `Ctrl + V` в терминале не работает).
4. После вставки команды нажмите **`Enter`**, чтобы она выполнилась.
5. **Важно про пароль:** когда команда начинается со слова `sudo`, терминал попросит ввести пароль от вашего компьютера:
   `[sudo] password for ...:`
   Начните печатать пароль на клавиатуре и нажмите **`Enter`**. **Буквы и звёздочки при вводе пароля не показываются — это нормально** (защита Linux), просто введите пароль вслепую и нажмите `Enter`.

## Шаг 3. Запустите сервер (выберите один из двух вариантов)

У вас есть два варианта запуска — выберите тот, который вам удобнее:

### Вариант 1. Максимально простой запуск из папки (`run-server.sh`)
Подходит, если вы хотите включать и выключать сервер вручную, когда он вам нужен.

Введите одну команду:
```bash
bash run-server.sh
```

**Что сделает эта команда сама:**
1. Проверит, установлен ли Node.js (если нет — сама скачает и установит свежий Node.js 24).
2. Установит все нужные библиотеки (`npm ci`).
3. Соберёт сайт (`npm run build`).
4. Создаст защищённую папку `psbees-data` для базы данных (`psbees.sqlite`).
5. Запустит сервер в фоновом режиме на порту `8080` и напишет готовые ссылки!

Вы увидите на экране примерно такое сообщение:
```text
Общий сервер PSBees запущен!
  Локально:           http://127.0.0.1:8080/
  Для других в сети:  http://192.168.1.50:8080/
  Админ-панель:       http://127.0.0.1:8080/admin
  База данных:        /home/имя/linux_pcb_app/psbees-data/psbees.sqlite
```

**Полезные команды для управления `run-server.sh`:**
- Проверить, работает ли сервер и узнать ссылки:
  ```bash
  bash run-server.sh status
  ```
- Остановить сервер:
  ```bash
  bash run-server.sh stop
  ```
- Запустить на другом порту (если порт `8080` занят):
  ```bash
  PORT=8090 bash run-server.sh
  ```
- Запустить прямо в текущем окне терминала (чтобы видеть все логи, остановка через `Ctrl + C`):
  ```bash
  bash run-server.sh --fg
  ```

---

### Вариант 2. Постоянный сервер на Ubuntu (`server-ubuntu.sh`)
Подходит для выделенного сервера или компьютера, чтобы PSBees **сам запускался в фоне при каждом включении компьютера** и автоматически перезапускался при сбоях.

Введите одну команду:
```bash
sudo bash server-ubuntu.sh install
```

**Никаких вопросов установщик задавать не будет.** Он сам:
1. Установит Node.js 24 LTS.
2. Скопирует программу в `/opt/psbees` и соберёт её.
3. Создаст базу данных в `/var/lib/psbees/psbees.sqlite`.
4. Настроит автозапуск через `systemd` (служба `psbees`).
5. Выведет ссылки для подключения.

**Команды управления системным сервером:**
- Посмотреть состояние сервера: `sudo bash server-ubuntu.sh status`
- Посмотреть логи сервера: `sudo bash server-ubuntu.sh logs` (выход из логов — клавиша `Q` или `Ctrl + C`)
- Перезапустить сервер: `sudo bash server-ubuntu.sh restart`
- Остановить сервер: `sudo bash server-ubuntu.sh stop`
- Запустить снова: `sudo bash server-ubuntu.sh start`
- Обновить сервер после `git pull` (все пользователи и платы сохранятся): `sudo bash server-ubuntu.sh update`
- Сделать резервную копию базы данных: `sudo bash server-ubuntu.sh backup`

## Шаг 4. Первый вход и получение прав Администратора

1. Сразу после запуска сервера откройте браузер на своём компьютере и перейдите по ссылке из терминала:
   - `http://127.0.0.1:8080/` (если браузер открыт на том же компьютере, где запущен сервер)
   - или `http://ВАШ_IP:8080/` (например, `http://192.168.1.50:8080/`)
2. Откроется окно **«Войти в PSBees»**.
3. В поле **«Ваше имя или ник»** напишите свой ник (например, `Данил`) и нажмите **«Войти»**.
4. **Важно:** так как вы вошли самым первым на чистый сервер, система **автоматически сделает вас Администратором**!
5. Чтобы открыть **Админ-панель**, перейдите по адресу:
   - `http://127.0.0.1:8080/admin` (или нажмите на своё имя в правом верхнем углу редактора → **«Перейти в админ-панель →»**).

В админ-панели вы можете:
- видеть всех зарегистрированных людей и их проекты;
- временно закрывать или открывать регистрацию новых ников;
- назначать других администраторов или блокировать/удалять лишние аккаунты;
- скачивать резервные копии любых плат в формате JSON.

## Шаг 5. Как другим людям подключиться и зарегистрироваться

### 1. Если вы в одной сети (один Wi-Fi роутер, офис, локальная сеть)
Отправьте другим людям ссылку со строчки **«Для других в сети»**, которую показал терминал при запуске, например:
```text
http://192.168.1.50:8080/
```
*(У вас вместо `192.168.1.50` будут ваши цифры из вывода терминала).*

### 2. Если друзья или коллеги находятся в другом доме / городе (через интернет)
Чтобы не настраивать роутер и «белый IP», проще всего использовать любую бесплатную программу виртуальной локальной сети:
- **Tailscale** (`tailscale.com`) или **ZeroTier** (`zerotier.com`) или **Radmin VPN**:
  1. Установите программу себе на сервер и людям, которые будут подключаться.
  2. Войдите в одну виртуальную сеть.
  3. Программа выдаст вашему серверу внутренний IP-адрес (например, `100.x.x.x` в Tailscale или `26.x.x.x` в Radmin VPN).
  4. Дайте людям ссылку `http://ВАШ_IP_ИЗ_VPN:8080/` — они сразу откроют ваш сервер!

### 3. Как другие люди регистрируются
1. Человек открывает вашу ссылку `http://...:8080/` в своём браузере (на Windows, Linux, Mac или планшете).
2. Вводит своё **имя или ник** (например, `Алексей`).
   - Если он просто нажмёт **«Войти»**, сервер сам создаст ему новый профиль и пустит в редактор.
   - Если он хочет убедиться, что чужой ник случайно не занят, он может нажать внизу **«Хотите проверить свободен ли ник? Отдельная регистрация»**, ввести ник и нажать **«Зарегистрироваться и войти»** (если ник уже занят кем-то другим, сервер предупредит об этом).
3. При следующем входе с любого устройства человек просто снова вводит свой ник и видит все свои сохранённые платы!

## Шаг 6. Как сохранять платы на сервере и работать вдвоём

### Сохранение платы на сервере
1. В редакторе нажмите кнопку **«Облако / Проекты»** в верхней панели (или `Ctrl + S`).
2. В окне **«Облачные проекты»** введите название платы и нажмите **«Сохранить копию»**.
3. После этого плата привязана к серверу, и все ваши дальнейшие изменения автоматически сохраняются на сервере.

### Совместная работа над одной платой вдвоём
1. Второй человек должен хотя бы один раз зайти на сервер под своим ником (например, `Алексей`).
2. Вы (владелец платы) открываете окно **«Проекты»**, находите нужную плату в списке и нажимаете кнопку **«Участники»**.
3. В поле **«Пригласить пользователя по имени (нику)»** пишете `Алексей` и нажимаете **«Добавить редактора»**.
4. Теперь у `Алексея` в разделе **«Проекты»** появится ваша плата с пометкой **«Общая»**.
5. Когда вы оба откроете эту плату, вы сможете рисовать дорожки и двигать детали **одновременно** — изменения передаются друг другу почти мгновенно!

### Общая библиотека деталей
- Слева в разделе **«Детали»** есть вкладка **«Общая»**.
- Любой пользователь может нажать на значок облака `☁` рядом со своей деталью в личной библиотеке (или кнопку **«Опубликовать все»**), и эта деталь сразу появится во вкладке **«Общая»** у всех людей на сервере.

## Частые вопросы и решение проблем (FAQ)

### 1. У меня работает по `127.0.0.1:8080`, а у других людей с другого компьютера не открывается
Скорее всего, на вашем компьютере включён брандмауэр (файрвол `ufw`), который не пускает входящие подключения на порт `8080`.
Выполните в терминале:
```bash
sudo ufw allow 8080/tcp
```
После этого проверьте ссылку `http://ВАШ_IP:8080/` с другого компьютера ещё раз.

### 2. Как узнать IP-адрес моего сервера, если я закрыл терминал?
В папке проекта выполните:
```bash
bash run-server.sh status
```
Или просто введите системную команду:
```bash
hostname -I
```
Первое число (например, `192.168.1.50`) — это адрес вашего компьютера в локальной сети. Ссылка для браузера будет `http://192.168.1.50:8080/`.

### 3. Ошибка «Порт 8080 уже занят» (EADDRINUSE)
Значит, на порту `8080` уже запущена другая программа или старая копия сервера.
- Чтобы остановить старую копию: `bash run-server.sh stop`
- Или запустите сервер на другом порту, например `8090`:
  ```bash
  PORT=8090 bash run-server.sh
  ```

### 4. Где лежат все сохранения и как не потерять их?
- При запуске через `bash run-server.sh` вся база лежит в файле:
  `~/linux_pcb_app/psbees-data/psbees.sqlite`
- При установке через `sudo bash server-ubuntu.sh install` база лежит в:
  `/var/lib/psbees/psbees.sqlite`
- При обновлении кода (`git pull`) эта папка **не удаляется и не перезаписывается** — все пользователи, платы и общая библиотека остаются на месте.
