# Установка PSBees на Windows — пошагово, для новичков

> Нужны **общие проекты, аккаунты и админ-панель** для нескольких компьютеров?
> Разверните [общий сервер](DEPLOY_SERVER.md) и откройте его адрес в браузере Windows.
> Установленный `PSBees.exe` по умолчанию работает локально и не поднимает общий сервер.

Два способа:

1. **Установщик `.exe`** — обычная программа: ярлык в меню «Пуск», свой значок, своё окно. Node.js не нужен. Рекомендуется.
2. **Из исходников** — если вы разработчик или хотите собрать установщик сами. Нужен Node.js 18+.

## Способ 1. Установщик (рекомендуется)

### Что скачать

На странице релизов GitHub:

<https://github.com/danilka-revin/linux_pcb_app/releases>

или во вкладке **Actions** репозитория (рабочий процесс **Windows**, если включён) лежат файлы:

| Файл | Зачем |
| --- | --- |
| **`PSBees-Setup-0.1.0.exe`** | Установщик. Ставит программу, ярлык в «Пуск» и на рабочий стол. |
| **`PSBees-portable-0.1.0.exe`** | Запуск без установки. Можно держать на флешке. |

Номер версии в имени файла может быть другим — берите самый свежий.

> Если релиза ещё нет — соберите установщик сами (раздел ниже) или включите GitHub Actions:
> скопируйте `scripts/win/windows.yml` в `.github/workflows/windows.yml` в репозитории.
> Тогда во вкладке **Actions** → **Windows** → **Artifacts** появится ZIP `layaut-windows` с обоими `.exe`.

### Установка

1. Запустите **`PSBees-Setup-….exe`**.
2. Windows может показать предупреждение SmartScreen («Неизвестное приложение»): это потому, что установщик не подписан сертификатом. Нажмите **«Подробнее»** → **«Выполнить в любом случае»**.
3. Выберите папку (по умолчанию — в вашем профиле, права администратора не обязательны) и нажмите «Установить».
4. После установки в меню «Пуск» появится **«PSBees»**. Запускается файл **`PSBees.exe`**.

Откроется окно редактора. Интернет не нужен.

### Обновление

Скачайте новый `PSBees-Setup-….exe` и установите поверх. Сохранённые платы не трогаются.

Автообновление из GitHub при запуске, как на Linux, в `.exe`-версии нет.

### Удаление

Параметры Windows → Приложения → **PSBees** → Удалить.
Или «PSBees» в меню «Пуск» → удаление (если ярлык создал установщик).
Файлы плат в «Загрузках» останутся.

Портативный `PSBees-portable-….exe` никуда не ставится: просто удалите файл.

## Способ 2. Запуск из исходников (для разработки)

Нужен **Node.js 18 или новее**: <https://nodejs.org/> (LTS). При установке оставьте галочку **Add to PATH**.

Затем в PowerShell или «Командной строке»:

```bat
git clone https://github.com/danilka-revin/linux_pcb_app.git
cd linux_pcb_app
run.cmd
```

`run.cmd` сам поставит зависимости, соберёт программу и откроет её в браузере по адресу `http://127.0.0.1:8080`.
Сервер останется в свёрнутом окне «PSBees».

Без git: на странице репозитория **Code** → **Download ZIP**, распакуйте и дважды щёлкните `run.cmd`.

Режим разработчика с горячей перезагрузкой:

```bat
npm install
npm run dev
```

Откройте в браузере адрес, который напишет Vite (обычно http://localhost:5173).

## Как собрать установщик `.exe` самому

Сборка **только на Windows** (NSIS). На Linux без wine установщик не получится.
Чтобы GitHub собирал его сам, положите `scripts/win/windows.yml` в `.github/workflows/windows.yml`.

```bat
git clone https://github.com/danilka-revin/linux_pcb_app.git
cd linux_pcb_app
npm ci
npm run dist:win
```

В папке `release\` появятся:

- `PSBees-Setup-0.1.0.exe` — установщик;
- `PSBees-portable-0.1.0.exe` — портативный запуск;
- `win-unpacked\PSBees.exe` — сама программа без установщика.

Команда `dist:win` скачает Electron и electron-builder во временные `node_modules` и **не меняет** `package.json` / `package-lock.json` Linux-установки.

## Где хранятся ваши платы

- **Ctrl + S** сохраняет проект в файл `*.laypcb.json` (браузер / окно предложит «Сохранить как», обычно в «Загрузки»).
- Открыть — **Ctrl + O**.
- Черновик текущей платы браузер/окно помнит само. Важные платы сохраняйте в файл.
- Экспорт для производства (Gerber, PNG 1:1, `.lay6`) — **Ctrl + E**.

## Если что-то пошло не так

**SmartScreen / «Система Windows защитила ваш компьютер»**
Установщик без цифровой подписи. «Подробнее» → «Выполнить в любом случае».

**Антивирус удалил `.exe`**
Ложное срабатывание на неподписанный установщик. Добавьте файл в исключения или соберите его сами (`npm run dist:win`).

**`run.cmd`: «Node.js не найден»**
Установите Node.js LTS с https://nodejs.org/ и **перезапустите** терминал (PATH обновляется после установки).

**Окно открылось, но пустая страница**
Пересоберите: удалите папку `dist` и снова `npm run dist:win` / `run.cmd`.

Не нашли свою ошибку — issue: <https://github.com/danilka-revin/linux_pcb_app/issues>

## Что внутри установщика

Установщик кладёт `PSBees.exe` (Electron) и собранный интерфейс. При запуске программа поднимает тот же локальный сервер, что и Linux-версия, на `127.0.0.1` (порт 8484 или следующий свободный) и показывает редактор в своём окне. Второй запуск не открывает второе окно — активирует уже запущенное.
