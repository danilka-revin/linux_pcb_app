# Установка PSBees на Ubuntu — пошагово, для новичков

> **Windows?** Вам сюда: **[INSTALL_WINDOWS.md](INSTALL_WINDOWS.md)** — установщик `PSBees-Setup.exe` и запуск `PSBees.exe`.

Эта инструкция для тех, кто никогда не работал с терминалом. Заранее ничего знать не нужно:
копируйте команды отсюда и выполняйте их по очереди. Обычно всё занимает 5–10 минут.

Подходит для Ubuntu 20.04, 22.04, 24.04, 26.04 и систем на её основе
(Kubuntu, Xubuntu, Linux Mint, Pop!_OS и т. п.).

**Понадобится:**

- интернет — только на время установки, потом программа работает без него;
- около 500 МБ свободного места;
- пароль от вашей учётной записи Ubuntu (тот, что вы вводите при входе в систему).

## Коротко — все команды подряд

Если терминал вам уже знаком, вот всё, что нужно. Выполняйте по одной строке:

```bash
sudo apt update && sudo apt install -y git
git clone https://github.com/danilka-revin/linux_pcb_app.git ~/linux_pcb_app
cd ~/linux_pcb_app && bash install-ubuntu.sh
```

Затем нажмите клавишу **Super** (с логотипом Windows), наберите «PSBees» и щёлкните по значку.
Установщик сам скачает Node.js и npm, если их нет или версия Node.js старее 18,
загрузит библиотеки приложения, соберёт его и создаст ярлык. Для установки Node.js
система попросит пароль администратора; приложение и ярлык ставятся в вашу домашнюю папку.

Ниже — то же самое, но подробно и с объяснением каждого шага.

## Шаг 1. Откройте терминал

Терминал — это окно, в которое команды вводят текстом.
Откройте его сочетанием клавиш **Ctrl + Alt + T**
(или нажмите **Super**, наберите «терминал» и нажмите **Enter**).

Пять правил работы с терминалом:

1. **Вставить** скопированную команду — **Ctrl + Shift + V** (обычное Ctrl + V здесь не работает)
   или правая кнопка мыши → «Вставить».
2. **Выполнить** команду — клавиша **Enter**.
3. Команда закончилась, когда снова появилась строка вида `имя@компьютер:~$`.
   Пока её нет — ждите и ничего не вводите.
4. Выполняйте команды **по одной и по порядку**.
5. Если терминал просит **пароль** (`[sudo] пароль для имя:`), введите пароль от своей учётной записи
   и нажмите **Enter**. Символы при вводе **не отображаются**, даже звёздочками, — так и должно быть.

## Шаг 2. Установите git

`git` скачает программу. Если он уже установлен, эту команду можно пропустить.

```bash
sudo apt update && sudo apt install -y git
```

`sudo` в начале команды означает «выполнить с правами администратора», поэтому система и спрашивает пароль.

## Шаг 3. Node.js и библиотеки приложения

Node.js — среда, в которой программа собирается и работает. Установщик сам проверит Node.js и npm:
если Node.js версии **18 или новее** и npm уже есть, он использует их; иначе скачает и установит Node.js 24 LTS
из официального репозитория NodeSource. Также установщик загрузит все npm-библиотеки проекта.

Если Node.js нужно установить, система попросит пароль администратора. Это требуется только для системных
пакетов Node.js; сама программа и ярлыки устанавливаются без прав администратора в вашу домашнюю папку.
Если на компьютере настроен nvm и доступен Node.js 18+, установщик использует его без переустановки.

## Шаг 4. Скачайте программу

```bash
git clone https://github.com/danilka-revin/linux_pcb_app.git ~/linux_pcb_app
```

В домашней папке появится папка `linux_pcb_app` с программой.
Перейдите в неё — следующие команды выполняются оттуда:

```bash
cd ~/linux_pcb_app
```

Знак `~` — сокращение для вашей домашней папки (в приложении «Файлы» это «Домашняя папка»).

<details>
<summary><b>Без git: если вы скачали ZIP-архив с GitHub (нажмите, чтобы раскрыть)</b></summary>

1. На странице <https://github.com/danilka-revin/linux_pcb_app> нажмите зелёную кнопку
   **Code** → **Download ZIP**.
2. Откройте «Файлы» → «Загрузки», щёлкните по архиву `linux_pcb_app-main.zip` правой кнопкой →
   «Извлечь сюда».
3. Откройте появившуюся папку `linux_pcb_app-main`, щёлкните правой кнопкой по пустому месту →
   «Открыть в терминале». Или в терминале выполните `cd ~/Загрузки/linux_pcb_app-main`
   (если система на английском — `cd ~/Downloads/linux_pcb_app-main`).
4. Продолжайте с шага 5.

Чтобы обновить такую копию, скачайте свежий ZIP, распакуйте его поверх старого и снова выполните шаг 5.

## Шаг 5. Установите программу

```bash
bash install-ubuntu.sh
```

Скрипт при необходимости установит Node.js 24 LTS и npm, скачает все библиотеки проекта,
соберёт программу и добавит ярлык в меню приложений (и на Рабочий стол, если он доступен).
Это занимает 1–3 минуты. При установке Node.js система может попросить пароль администратора.
Промежуточные строки можно не читать — важно, чем всё закончится.
Если всё прошло успешно, в конце будет:

```text
==> Готово!
  • Ярлык «PSBees — редактор печатных плат» появился в меню приложений:
    нажмите клавишу Super (с логотипом Windows) и наберите «PSBees».
  • Адрес программы в браузере:  http://127.0.0.1:8484
```

**Не пишите `sudo`** перед этой командой. Если Node.js нужно установить, скрипт сам запросит
пароль администратора; приложение, запускающая команда и ярлыки ставятся в вашу домашнюю папку (`~/.local`).

## Шаг 6. Запустите

1. Нажмите клавишу **Super** или кнопку «Показать приложения» (девять точек внизу боковой панели).
2. Наберите **PSBees** (подойдут и «плат» или «pcb»).
3. Щёлкните по значку **«PSBees — редактор печатных плат»**.

В браузере откроется редактор по адресу `http://127.0.0.1:8484`. Это не сайт в интернете:
программа работает на вашем компьютере, интернет ей не нужен.

- Чтобы значок всегда был под рукой: правой кнопкой по нему → «Добавить в избранное»
  (или «Закрепить на панели»).
- Из терминала программу запускает команда `psbees` (со следующего входа в систему;
  сразу после установки — `~/.local/bin/psbees`).
- Закончили работу — просто закройте вкладку браузера. Маленький сервер программы
  останется работать в фоне до выключения компьютера — это нормально, ресурсов он почти не тратит.

## Где хранятся ваши платы

- **Ctrl + S** (или значок дискеты на верхней панели) сохраняет проект в файл `*.laypcb.json`.
  Браузер кладёт его в папку «Загрузки» (`~/Загрузки` или `~/Downloads`).
  Открыть сохранённый проект — **Ctrl + O** (или значок папки).
- Кроме того, текущую плату автоматически запоминает браузер, и при следующем запуске она откроется сама.
  Но это черновик: он пропадёт, если очистить данные браузера. Важные платы сохраняйте в файл.
- Экспорт для производства (Gerber + сверловка, PNG 1:1 для ЛУТ, `.lay6` для Sprint-Layout) — **Ctrl + E**.

## Как обновить до свежей версии

**Обновление теперь автоматическое.** При каждом запуске (ярлык в меню или `run.sh`)
программа сама проверяет GitHub: если в ветке `main` появился новый коммит —
скачивает, собирает и запускает новую версию, перезапустив сервер. Текущая версия
видна в меню «О программе». Сохранённые платы при этом не трогаются.

Если при запуске нет интернета (или сборка новой версии не удалась) — программа
запустит уже установленную версию, и повторит попытку при следующем запуске.
Журнал проверок — `~/.local/share/psbees/update.log`.

Ручное обновление (если хочется сделать прямо сейчас, не перезапуская):

```bash
cd ~/linux_pcb_app
bash install-ubuntu.sh
```

Свежие коммиты установщик подтянет сам (`git pull` перед сборкой), отдельно делать
`git pull` не нужно. Если редактор был открыт, обновите вкладку клавишей **F5**.
Сохранённые платы не пострадают.

Если при обновлении написано «Внимание: не удалось обновить автоматически», значит в папке
`~/linux_pcb_app` есть ваши изменения в файлах программы. Если вы их не делали, отмените
случайные правки и повторите:

```bash
cd ~/linux_pcb_app && git checkout -- . && bash install-ubuntu.sh
```

## Как удалить

```bash
pkill -f psbees/server.mjs
rm -rf ~/.local/share/psbees ~/.local/bin/psbees ~/.local/share/applications/psbees.desktop
DESKTOP_DIR="$(xdg-user-dir DESKTOP 2>/dev/null || printf '%s' "$HOME/Desktop")"; [ "$DESKTOP_DIR" = "$HOME" ] || rm -f "$DESKTOP_DIR/psbees.desktop"
rm -rf ~/linux_pcb_app
```

Первая строка останавливает фоновый сервер программы, вторая удаляет установленную программу и ярлык в меню,
третья — ярлык на Рабочем столе, четвёртая — скачанную папку. Файлы плат в «Загрузках» останутся.
Node.js можно оставить или удалить командой `sudo apt remove -y nodejs`.

## Запуск без установки

Чтобы попробовать программу, не добавляя значок в меню:

```bash
cd ~/linux_pcb_app
bash run.sh
```

Скрипт сам соберёт программу (при первом запуске и после обновления) и откроет её
по адресу `http://127.0.0.1:8080`. Если нужен другой порт — `PORT=8090 bash run.sh`.

Учтите: браузер хранит черновик отдельно для каждого адреса. Поэтому у версии из меню (`:8484`)
и у `run.sh` (`:8080`) черновики разные. Переносите платы через файл: **Ctrl + S** / **Ctrl + O**.

## Если что-то пошло не так

Найдите в списке сообщение, похожее на ваше.

**`E: Could not get lock /var/lib/dpkg/lock-frontend`** (или «Не удалось получить доступ к файлу блокировки»)
Система сейчас сама ставит обновления. Подождите 5–10 минут и повторите команду.
Не удаляйте файлы блокировки вручную.

**`Command 'git' not found`**
Пропущен шаг 2. Установите git командой `sudo apt update && sudo apt install -y git`.

**Установщик не смог поставить Node.js автоматически**
Проверьте подключение к интернету и повторите `bash install-ubuntu.sh`. Если автоматическая установка
не подходит вашей системе, установите Node.js 18+ и npm вручную и повторите установку.

**При установке Node.js: `trying to overwrite '/usr/include/node/common.gypi'` или `…/node.stp`**
Мешают остатки старого Node.js из Ubuntu. Удалите их и повторите установку:

```bash
sudo apt remove --purge -y nodejs npm libnode-dev nodejs-doc && sudo apt autoremove -y
sudo apt install -y nodejs
```

**`bash: install-ubuntu.sh: No such file or directory`** (или «Нет такого файла или каталога»)
Вы не в папке программы. Выполните `cd ~/linux_pcb_app` и повторите.

**`fatal: not a git repository`** при `git pull`
Программа скачана ZIP-архивом, а не через git. Обновляйте её так же — свежим ZIP-архивом
(см. «Без git» в шаге 4) — или скачайте заново через `git clone` (шаг 4).

**`fatal: destination path '…linux_pcb_app' already exists`**
Программа уже скачана. Выполните `cd ~/linux_pcb_app` и продолжайте с шага 5
(или обновите её — см. «Как обновить до свежей версии»).

**`Ошибка: не запускайте … через sudo`, `EACCES` или «Отказано в доступе»**
Команды `bash install-ubuntu.sh` и `bash run.sh` запускаются **без** `sudo`. Если раньше
вы всё же запускали их через `sudo`, верните себе права на папку и повторите установку:

```bash
sudo chown -R "$USER": ~/linux_pcb_app
cd ~/linux_pcb_app && bash install-ubuntu.sh
```

**Значка нет в меню**
Подождите несколько секунд или выйдите из системы и войдите снова.
А пока программу можно запустить из терминала: `~/.local/bin/psbees`.

**`psbees: command not found`**
После первой установки эта короткая команда начинает работать со следующего входа в систему.
До тех пор используйте полный путь: `~/.local/bin/psbees`.

**Браузер открылся, но пишет «Не удаётся соединиться» / «Unable to connect»**
Не запустился сервер программы. Причина записана в журнале:

```bash
cat ~/.local/share/psbees/server.log
```

- `EADDRINUSE` — порт 8484 занят другой программой. Переустановите PSBees на другой порт
  (он запомнится и при следующих обновлениях):

  ```bash
  cd ~/linux_pcb_app && PCB_APP_PORT=8485 bash install-ubuntu.sh
  ```
- Если вы переустанавливали Node.js, повторите `bash install-ubuntu.sh` в папке программы.

Проверить, работает ли сервер: откройте в браузере `http://127.0.0.1:8484/healthz`
(если меняли порт — подставьте свой) — должно появиться `{"ok":true}`.

**После обновления открылась старая версия или пустая страница**
Обновите страницу без кэша: **Ctrl + F5** (или **Ctrl + Shift + R**).

**«Ничего не появилось»: нет «Конструктора интерфейса», «Цветов интерфейса» или «Обновить»**
Эти кнопки живут в правом углу верхней панели, в группе с меню «⋯»:

- тема (солнце/луна) и **«Обновить»** — отдельными кнопками;
- **«⋯» → «Интерфейс и справка»** — пункты «Конструктор интерфейса…», «Цвета интерфейса…»,
  «О программе».

В узком окне верхняя строка листается колесом мыши, но эта группа всегда прижата к правому
краю — она остаётся видна, а скрыть её конструктором нельзя (иначе вход в настройки пропал бы
вместе с ними). Если кнопок нет совсем — значит установлена старая сборка: конструктор
собирает программу из папки `~/linux_pcb_app`, и если её давно не обновляли, ставилась
старая версия. Посмотрите версию в «⋯ → О программе» и переустановите — установщик сам
подтянет свежие коммиты:

```bash
cd ~/linux_pcb_app && bash install-ubuntu.sh
```

**`npm ERR! network`, `ETIMEDOUT` или `ECONNRESET` во время установки**
Проблема с интернетом. Проверьте подключение и повторите `bash install-ubuntu.sh`.

Не нашли свою ошибку — создайте issue: <https://github.com/danilka-revin/linux_pcb_app/issues>
и приложите к нему текст из терминала (скопировать выделенное в терминале — **Ctrl + Shift + C**).

## Что делает install-ubuntu.sh

Для любопытных. Скрипт:

1. проверяет Node.js 18+ и npm, а если их нет — скачивает и устанавливает Node.js 24 LTS;
2. подтягивает свежие коммиты из GitHub (`git fetch` + `git pull --ff-only`): установщик
   собирает программу из папки проекта, поэтому без этого шага можно было поставить старую
   версию. Если в папке есть ваши изменения или нет интернета, обновление пропускается —
   собирается то, что есть, а в конце об этом пишется предупреждение;
3. скачивает библиотеки (`npm ci`) и собирает программу (`npm run build`) в папке проекта;
4. копирует собранную программу в `~/.local/share/psbees` (вместе со скриптом
   автообновления `update.mjs` и меткой установленной версии `version.txt`);
5. создаёт команду запуска `~/.local/bin/psbees` (при запуске она сначала
   проверяет обновления в GitHub — см. «Как обновить до свежей версии»);
6. добавляет ярлык в меню приложений (`~/.local/share/applications/psbees.desktop`)
   и на Рабочий стол, если соответствующая папка существует;
7. печатает версию установленной сборки — её же показывает «⋯ → О программе».

При запуске значок поднимает маленький локальный веб-сервер на порту 8484 (если тот ещё не запущен)
и открывает программу в браузере по умолчанию. Журнал сервера — `~/.local/share/psbees/server.log`.
Другой порт задаётся при установке: `PCB_APP_PORT=8485 bash install-ubuntu.sh`.
