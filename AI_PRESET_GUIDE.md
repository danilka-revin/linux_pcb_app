1.  **Получи API ключ на TeamoRouter:**
    - Открой https://teamorouter.com/
    - Зарегистрируйся через Google (1 клик, карта не нужна, VPN не нужен)
    - Зайди в раздел API Keys → Create new key, скопируй ключ формата `tr-...`

2.  **Вставь ключ в конфиг:**
    - Открой файл `.env.teamo.example` в корне проекта
    - Замени строку `TEAMO_API_KEY=tr-ВСТАВЬ_СВОЙ_КЛЮЧ_ТУТ` на свой ключ
    - Сохрани файл и переименуй его в `.env` (чтобы получилось `.env` в корне проекта)

3.  **Установи зависимости:**
    Запусти в терминале в корне проекта:
    ```bash
    npm install openai dotenv
    ```

✅ ГОТОВО! Больше ничего настраивать не нужно.

## Как использовать в коде:
В любом месте проекта просто импортируй готовую функцию:
```js
import chatCompletion from './src/utils/aiClient.js';

// Простой запрос (быстрая модель)
const answer = await chatCompletion({
  messages: [
    { role: 'user', content: 'Проверь эти соединения на схеме на короткое замыкание' }
  ]
});
console.log(answer.choices[0].message.content);

// Запрос для агента с вызовом инструментов (умная Pro модель)
const agentAnswer = await chatCompletion({
  useSmartModel: true, // Включает умную Pro модель для сложных рассуждений
  messages: [...],
  tools: [...твои инструменты...],
  tool_choice: 'auto'
});
```

## Если закончится дневной лимит на TeamoRouter:
1.  Зайди на https://router.bynara.id/, зарегистрируйся через Google
2.  Привяжи Telegram и вступи в их канал (занимает 10 секунд, бесплатно)
3.  Создай API ключ формата `sk-nry-...`
4.  Вставь его в строку `NARA_API_KEY=` в твоем `.env` файле

Клиент автоматически будет переключаться на NaraRouter если Teamo упал/закончил лимит, тебе ничего в коде менять не нужно!
