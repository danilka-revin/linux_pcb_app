# 🎯 ГОТОВЫЙ ПРЕСЕТ БЕСПЛАТНОГО AI ДЛЯ АГЕНТА

## ⚠️ Сначала главное: как включить ИИ-агента в самой программе

Программа PSBees — браузерное приложение. Оно **не читает `.env`** и не
использует `src/utils/aiClient.js` (этот файл — для Node-скриптов, см. ниже).
Ключ вводится прямо в программе:

1. Запусти приложение (`npm run dev` или `bash run.sh`) и открой
   **Настройки (шестерня) → ИИ-помощник**.
2. Поставь галку **«Включить ИИ-режим»**.
3. **Сервис:** `TeamoRouter (бесплатно)` — адрес и модель подставятся сами:
   `https://api.teamorouter.com/v1` и `deepseek-v4-flash-free`.
4. **API-ключ:** вставь свой ключ `tr-…` (где взять — ниже).
5. Нажми **«Проверить связь»** — должно написать «Связь есть! Модель ответила: …».
6. Пиши помощнику свободные просьбы: «сделай мигалку на двух светодиодах»,
   «что не так с этой платой?».

Ключ хранится только в `localStorage` этого браузера и никуда не отправляется,
кроме выбранного API. В файл «Перенос настроек» он не попадает.

Другие бесплатные/платные пресеты в том же списке: **DeepSeek**
(`deepseek-v4-flash`), **NaraRouter** (запасной бесплатный), **OpenAI**,
**OpenRouter**, **Ollama** (локально, без ключа) и **Свой адрес**.

## 🩺 Если ошибка «404»

`404` означает, что запрос дошёл до сервера, но путь или имя модели не те.
В тексте ошибки программа показывает, куда именно она стучалась
(`…/chat/completions · модель «…»`) — смотри на этот адрес.

| Симптом | Причина | Что сделать |
| --- | --- | --- |
| `404`, адрес без `/v1` (например `https://api.teamorouter.com/chat/completions`) | у шлюза нет такого пути | допиши `/v1` к адресу: `https://api.teamorouter.com/v1`. Программа сама добавляет `/v1` известным шлюзам (OpenAI, OpenRouter, TeamoRouter, NaraRouter) — проверь, что адрес не переписан вручную с ошибкой |
| `404` + `Model Not Exist` от DeepSeek | имя `deepseek-chat` / `deepseek-reasoner` отключено 24.07.2026 | поставь модель `deepseek-v4-flash` (или `deepseek-v4-pro`) |
| `404` + `No endpoints found for model name` от OpenRouter | такого ID нет в каталоге | скопируй точный ID с openrouter.ai/models (бесплатные заканчиваются на `:free`) |
| `404` от своей же страницы (адрес вида `http://localhost:8080/api.…`) | в поле «Адрес API» не хватало `https://` | программа теперь добавляет схему сама; перепроверь, что адрес сохранён |
| `401` | ключ не подошёл/не активирован | пересоздай ключ, вставь без пробелов |
| `429` / `402` | кончился дневной лимит (200 запросов) | подожди до 00:00 UTC или перейди на NaraRouter / платную модель (`deepseek-v4-flash` без `-free`) |
| «Нет связи с API» (не 404) | провайдер не разрешает запросы из браузера (CORS) или нет сети | возьми пресет, который работает из браузера (TeamoRouter/OpenRouter/Ollama), или запусти Ollama с `OLLAMA_ORIGINS=*` |

## 🔑 Где взять бесплатный ключ TeamoRouter

1. Открой https://teamorouter.com/
2. Зарегистрируйся через Google (1 клик, карта не нужна, VPN не нужен)
3. Зайди в раздел **API Keys → Create new key**, скопируй ключ формата `tr-...`
4. Вставь его в **Настройки → ИИ-помощник → API-ключ** (см. первый раздел)

Новым аккаунтам дают по 200 бесплатных запросов в день на модели
`deepseek-v4-flash-free` и `deepseek-v4-pro-free` (сброс в 00:00 UTC).

## 🔁 Если закончился дневной лимит на TeamoRouter

1. Зайди на https://router.bynara.id/, зарегистрируйся через Google
2. Привяжи Telegram и вступи в их канал (занимает 10 секунд, бесплатно)
3. Создай API ключ формата `sk-nry-...`
4. В программе выбери пресет **NaraRouter (запасной, бесплатно)** и вставь ключ

## 📜 Сценарий для Node-скриптов (`.env` + `src/utils/aiClient.js`)

Это отдельный путь — **только для своих серверных скриптов** (не для интерфейса
программы). Клиент умеет автоматический фоллбэк на резервного провайдера,
tool calling и режим размышлений.

1. Скопируй `.env.teamo.example` в `.env` и вставь ключ:
   `TEAMO_API_KEY=tr-твой-ключ` (при желании — `NARA_API_KEY=sk-nry-…`).
2. Зависимости уже в `package.json` (`openai`, `dotenv`); после `npm ci`
   ничего доустанавливать не нужно.
3. Используй в своём `.mjs`-скрипте:

```js
import chatCompletion from './src/utils/aiClient.js';

// Простой запрос (быстрая модель)
const answer = await chatCompletion({
  messages: [{ role: 'user', content: 'Проверь эти соединения на короткое замыкание' }],
});
console.log(answer.choices[0].message.content);

// Запрос для агента с вызовом инструментов (умная Pro модель)
const agentAnswer = await chatCompletion({
  useSmartModel: true,
  messages: [/* … */],
  tools: [/* твои инструменты */],
  tool_choice: 'auto',
});
```

В `.env` адреса уже указаны правильно — с `/v1`:
`TEAMO_BASE_URL=https://api.teamorouter.com/v1`,
`NARA_BASE_URL=https://router.bynara.id/v1`. Без `/v1` оба шлюза отвечают `404`.
